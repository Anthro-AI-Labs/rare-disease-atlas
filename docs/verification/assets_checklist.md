## How to use

1. Open each **source_url** yourself.
2. Do the check written under the row.
3. Tick the box. When verified, remove `AI-CHECKED, NOT YET MANUALLY VERIFIED.` from that row's notes in the CSV.
4. If something is wrong, write it under the gene's **My notes** and ping Amin.

**Status words:** for NCT studies, status is copied exactly from ClinicalTrials.gov (RECRUITING, COMPLETED, TERMINATED, UNKNOWN = sponsor stopped updating). For other assets: enrolling / active / unknown, based only on the page.

⚠️ **Multi-gene rows:** the same NCT appears under several genes on purpose (NCT06555965, NCT05232630, NCT05818553, NCT01238250). Check it once, tick all copies.
